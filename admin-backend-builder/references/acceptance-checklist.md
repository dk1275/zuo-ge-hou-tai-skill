# 后台上线验收清单

## 内容与表单

- [ ] 新增、编辑、关闭后重开，标题/名称/摘要/状态/关联 ID/图片都能回填。
- [ ] 富文本、结构化模块顺序、模块 ID、空数组和历史兼容格式均可保存。
- [ ] 编辑栏中的 H5/移动端预览在输入、选择、模块变更、排序和本地图片变化后实时更新，不依赖先保存。
- [ ] 预览与客户端页面共享数据契约，图片在稳定 URL/私有临时态下均有明确表现。
- [ ] H5 预览只读编辑态，不触发真实收藏、分享、导航、发布或写库动作。
- [ ] 空输入、非法枚举、过长文本、越界关联会阻止保存并保留表单。

## 权限与审核

- [ ] 未登录不能看到受保护数据或调用管理写接口。
- [ ] 编辑角色不能执行管理员动作；改请求体中的角色/状态/创建者字段也无效。
- [ ] 审核通过只执行一次；拒稿、补充、删除和纠错都有审计记录。
- [ ] 投稿图片在审核前不公开；发布后才进入公开内容媒体路径。

## 可靠性

- [ ] 连点保存只产生一次写入；超时/5xx 后能重试且不重复。
- [ ] 云端失败不解锁页面、不生成本地假数据、不清空用户输入。
- [ ] 不存在的 ID 返回可识别 `NOT_FOUND`，而不是笼统内部错误。
- [ ] 列表分页、导入、刷新按稳定 ID 合并，不出现重复行。

## 部署与验收边界

- [ ] 语法/类型/单元测试和项目发布门禁通过。
- [ ] 线上详情确认代码版本、运行时、入口、内存、超时、依赖、环境变量和触发器。
- [ ] 线上只读列表、详情、鉴权失败和一个安全失败路径已调用验证。
- [ ] 交付报告区分：已实现、已验证、已部署、待用户手动验收；写明回滚依据。
